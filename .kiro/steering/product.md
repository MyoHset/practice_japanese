# Pocket JLPT

A Flutter mobile application designed to help Burmese learners practice for the Japanese Language Proficiency Test (JLPT).

## Purpose
Study aid app focused on JLPT exam preparation with quiz/practice functionality.

## Target Users
Burmese-speaking learners studying for JLPT (levels N5-N1).

## Key Features
- JLPT level-based practice (N5 through N1)
- Interactive quiz/practice mode
- Library of vocabulary and grammar
- Past exam practice
